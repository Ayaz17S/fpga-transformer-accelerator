# microGPT FPGA accelerator — RTL

SystemVerilog RTL for a ~4,192-parameter GPT-style Transformer on the PYNQ-Z2
(`xc7z020clg400-1`). Numeric rules (formats, rounding, test-vector files) are
in the shared contract doc.

## Layout

| Folder | Contents |
| --- | --- |
| `rtl/` | Synthesizable design: `model_pkg.sv` (dimensions + weight memory map), `mac.sv`, `requant.sv`, `matvec.sv`, `weight_rom.sv`, `embed.sv` |
| `tb/`  | Self-checking testbenches, one per unit, plus `tb_pkg.sv` (shared reference functions) |
| `data/` | ROM images (`weights_all.mem`) |
| `scripts/` | `gen_placeholder_weights.py`: random weights in the ROM layout, until trained weights arrive |
| `sim/` | `run.bat` plus one source list (`<tb>.f`) per testbench |
| `syn/` | Out-of-context synthesis script (resources + 100 MHz timing) |
| `build/` | Generated by the scripts; safe to delete |

## Run from a terminal (from this folder)

```
python scripts/gen_placeholder_weights.py
sim\run.bat tb_mac
sim\run.bat tb_matvec
sim\run.bat tb_embed
vivado -mode batch -source syn/synth.tcl -tclargs matvec xc7a35tcpg236-1
```

Drop the part argument once Zynq-7000 device support is installed; the
default part is the PYNQ-Z2's.

## Run in the Vivado GUI

1. Create Project → RTL Project → choose the PYNQ-Z2 part (or any Artix-7
   until Zynq-7000 support is installed).
2. Add Sources → Design sources → every file in `rtl/`, plus
   `data/weights_all.mem` (so `$readmemh` finds it).
3. Add Sources → Simulation sources → `tb/tb_pkg.sv` and the testbench from
   `tb/` you want.
4. In the Sources pane, under Simulation Sources, right-click the testbench →
   Set as Top.
5. Flow Navigator → Run Simulation → Run Behavioral Simulation. The Tcl
   console prints PASS or FAIL; drag signals into the waveform to inspect them.
